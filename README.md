1. Для декомпозиции существующего фронтенда я выбрал Webpack Module Federation по следующим причинам:
    * Сбор и учет лаков я решил выделить в отдельный микрофронтенд. В рамках существующего функционала это может показаться избыточным решением, т.к. у лайков сильная зависимостть с фото. Но это упростит разработку и поддержку в случае расширения функционала лайков. Из-за сильной связности между будущими модулями возможность предоставляемая Webpack Module Federation использовать общий код и shared dependencies будет полезна
    * В данном приложении нет сильно отличающихся функциональностей - нет работы с платежами, сложными формами т.п. В следствии чего важная особенность Single SPA в виде использования нескольких фреймворков не требуется.
